# Zombies Ultimate Collection

Download the standalone build from [Releases](../../releases) for Call of Duty: Black Ops II Zombies on Plutonium.

1. Download `zuc_pre_v###.zip` under **Assets** on the release page.
2. Close the game. Open the ZIP with 7-Zip and extract its `storage` folder into `%LOCALAPPDATA%\Plutonium`. The mod should be at `%LOCALAPPDATA%\Plutonium\storage\t6\mods\zm_zuc`.
3. Launch BO2 Zombies in Plutonium and select **Zombies Ultimate Collection** from **Mods**.
